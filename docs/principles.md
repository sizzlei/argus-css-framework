# 디자인 원칙 — 한 페이지

리뉴얼할 때 판단이 갈리면 이 페이지를 기준으로 한다. 규칙은 짧게, 예외는 적게.

## 1. 한 화면에 하나만 강조한다
- 액센트 카드(`.ag-card--accent`)는 화면당 **1개**. 둘이 필요하면 두 번째는 `--accent-soft`.
- 큰 숫자(`.ag-stat__value`)도 한 줄에 **3~4개**까지. 그 이상이면 테이블.
- 버튼은 한 영역에 primary **1개**. 나머지는 outline / ghost.

## 2. 첫 화면은 가볍게
- 대시보드 스크롤 전 영역: 카드 **7개 이하**. 핵심 지표 3~4 + 차트 1 + 보조 2.
- 목록 화면: 필터 바 1줄 + 테이블. 요약 스탯은 4개까지만 위에.
- 상세 화면: 헤더(이름·상태·액션) → 경고 배너(있으면) → 지표 4 → 탭. 우측 컬럼은 타임라인·연관 리소스.

## 3. 상태는 색만으로 말하지 않는다
- 상태색(good / warn / crit / info)은 **상태에만** 쓴다. 차트 시리즈, 장식, 브랜드에 쓰지 않는다.
- 엔진·태그·팀처럼 **종류**를 구분할 때는 범주색 `cat1~4` (`.ag-badge--cat1`, `.ag-tag--cat1`, `.ag-dot--cat1`). 차트 범주색과 같은 네 가지라 범주 1 은 어디서나 같은 색. 다섯 번째 범주는 만들지 않는다 → 기본 배지로 "기타".
- 상태 표시는 항상 점·아이콘·텍스트 중 하나가 색과 함께 간다 (`.ag-badge` 안에 `.ag-dot`, 또는 라벨).
- 흰 바탕 단독 텍스트는 `--ag-*-text` 토큰 (`.ag-text-warn` 등). 뱃지 안은 기본 상태색.

## 4. 서비스 색은 다르되, 나머지는 같다
- 앱마다 액센트가 다를 수 있다 (`themes/<color>.min.css`). 그것이 앱을 구분하는 유일한 색 차이다.
- 표면·텍스트·간격·라운드·상태색·차트 범주색은 모든 서비스가 같다. 바꾸고 싶으면 프레임워크에서 바꾼다.

## 5. 메뉴 수가 레이아웃을 정한다
| 메뉴 | 모드 |
|---|---|
| 4~6개, 그룹 없음 | `ag-app` (top) |
| 5~7개, 아이콘으로 식별, 모바일 많음 | `--rail` |
| 그룹이 있는 10개 이상 | `--sidebar` |
| 상단에 검색·사용자 행이 필요하고 메뉴는 한 줄 | `--tabs` |
| 설정·마법사·긴 폼 | `--focus` |
| 목록 보며 하나 열어보기 | `--dual` |
- 한 서비스 안에서 화면별로 섞어도 된다. 상단 바와 `.ag-user` 자리는 바뀌지 않는다.

## 6. 숫자는 열이 맞아야 한다
- 숫자가 있는 곳은 `tabular-nums` (table, stat, badge, `.ag-num` 에 내장).
- 금액·용량·비율은 단위를 작게 뒤에 (`<small>`). 천 단위 구분자 필수.
- 시각은 `HH:MM`, 날짜는 `9/21` 또는 `2026-09-21` — 한 화면에서 섞지 않는다.

## 7. 텍스트 위계는 세 단계면 충분하다
- 본문 14 / 보조 13 / 메타 11. 메타는 `--ag-text-3`. 그보다 작게 쓰지 않는다.
- 제목은 크기·굵기로 구분하고, 색으로 구분하지 않는다.
- 뱃지 안에 문장을 넣지 않는다 (2~3단어). 카드 제목은 한 줄.

## 8. 쓰지 말 것
- 카드 안의 카드 안의 카드 (3단). 2단까지.
- 탭 7개 이상 → 사이드바 그룹이나 드롭다운으로.
- 모달 안의 모달. 두 번째는 드로어나 인라인 확장.
- 토스트에 중요한 내용. 토스트는 "저장됨" 같은 확인용. 판단이 필요하면 배너나 모달.
- Tailwind/Bootstrap 유틸로 간격 조정. 간격은 컨테이너(`.ag-main` · `.ag-grid` · `.ag-stack` · `.ag-cluster`)가 가진다. 카드 사이는 `--ag-gap-grid`(24px), 본문 블록 사이는 `--ag-gap-main`(32px) — 조이고 싶으면 토큰을 바꾼다. 클래스 없는 부모 안에 카드·버튼을 그냥 나란히 두어도 기본 간격 폴백이 붙는다.
- hex 리터럴. 토큰만.
- `.ag-tile` 에 세로 콘텐츠. 기본 타일은 라벨↔값 가로 배치라 가운데가 빈다 → `.ag-tile--stack` 또는 `.ag-card--sm`.
- `.ag-form-grid`(auto-fit) 에 `.ag-field--full` 섞기. 넓은 화면에서 트랙이 잘게 쪼개진다 → `.ag-form-grid--2/--3/--4` 로 열 고정. 폼이 아닌 균등 분할은 `.ag-grid` + `.ag-col-*`.
